OpsProof 학습 참고 · Lesson 1

kind × OpsProof 치트시트

kind는 Docker 컨테이너를 Kubernetes node로 사용하는 로컬 cluster 도구다. 이 프로젝트의 cluster 이름은 opsproof, kubectl context 이름은 kind-opsproof다.

세 층을 구분

host macOS └─ Docker container: opsproof-control-plane ← Kubernetes node └─ Kubernetes cluster: opsproof └─ namespace: opsproof → Pods / Jobs / Deployment

명령 지도

# kind: cluster 자체
kind get clusters
kind get nodes --name opsproof
kind delete cluster --name opsproof

# kubectl: cluster 안 Kubernetes resource
kubectl --context kind-opsproof cluster-info
kubectl --context kind-opsproof get nodes
kubectl --context kind-opsproof -n opsproof get pods,jobs,deployment,statefulset

# Docker image → kind node (앱 코드를 수정/재빌드했을 때)
docker build -t opsproof/order-api:v1 .
kind load docker-image opsproof/order-api:v1 --name opsproof

이 저장소에서는

make cluster-up     # kind create cluster --name opsproof ...
make build-images   # Docker build/tag + kind load docker-image
make baseline       # Kubernetes resource 배포 및 대기
make cluster-down   # kind delete cluster --name opsproof

핵심: kind get clusters의 opsproof는 “cluster가 있다”는 뜻이다. 앱 image가 node에 있고, namespace 안 workload가 Ready라는 뜻은 아니다.

막혔을 때

kind export logs ./kind-logs --name opsproof
docker ps --format 'table {{.Names}}\t{{.Status}}'
kubectl --context kind-opsproof get events -A --sort-by=.lastTimestamp
