헷갈리기 쉬운 세 경계

  1. Helm release ≠ 하나의 Pod. k8s-monitoring은 Alloy Operator와 여러 collector workload를 설치하는 한 release다.
  2. OTLP ≠ 저장소. 앱이 telemetry를 보내는 protocol이다. 이 Lab에서는 trace만 OTLP로 보낸다.
  3. Grafana ≠ 판정기. Grafana는 Loki·Tempo·Prometheus를 읽는다. Deployment Gate의 PASS/FAIL은 Synthetic Check Job이 정한다.

고장 찾기: “요청 하나가 왜 실패했나?”는 Tempo → Loki. “언제부터 얼마나 자주 실패했나?”는 Prometheus. “계약이 통과했나?”는 Synthetic Check Job이다.
